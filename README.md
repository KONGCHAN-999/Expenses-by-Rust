# ລາຍຮັບ-ລາຍຈ່າຍ — แอปจดรายรับรายจ่าย (ภาษาลาว · เงินกีบ)

เว็บแอปจดรายรับรายจ่ายสำหรับใช้คนเดียวบนมือถือ ทำงานออฟไลน์ได้ ข้อมูลทั้งหมดเก็บอยู่ในเครื่อง (localStorage) ไม่มีเซิร์ฟเวอร์
เขียนด้วย Rust ทั้งหมด: **Leptos 0.8 (CSR)** คอมไพล์เป็น WebAssembly ด้วย **Trunk**

## ฟีเจอร์

- **ໜ້າຫຼັກ (หน้าหลัก)**: ยอดคงเหลือของเดือน รายรับ/รายจ่ายรวม 3 หมวดที่ใช้เงินมากสุด รายการล่าสุด และแถบเตือนเมื่อไม่ได้สำรองข้อมูลเกิน 14 วัน
- **ເພີ່ມ/ແກ້ໄຂລາຍການ**: เลือกรายจ่ายหรือรายรับ ใส่จำนวนเงิน (กีบ ไม่มีทศนิยม) หมวด วันที่ และโน้ต
- **ລາຍການ (รายการ)**: แยกตามวัน ค้นหาได้ กรองตามประเภทหรือหมวด แตะเพื่อแก้ไข ปัดซ้ายเพื่อลบ และกด "ຍົກເລີກ" เพื่อกู้คืนได้
- **ສະຫຼຸບ (สรุป)**: ดูรายเดือนหรือรายปี กราฟวงกลมแยกตามหมวด กราฟแท่งเทียบรายรับกับรายจ่าย แตะแท่งเพื่อไปดูเดือนนั้น
- **ຕັ້ງຄ່າ (ตั้งค่า)**: ส่งออก .json (ไฟล์สำรอง) และ .csv (เปิดใน Excel) นำเข้า .json/.csv แบบรวมกับข้อมูลเดิมหรือแทนที่ทั้งหมด จัดการหมวด ธีมสว่าง/มืด และลบข้อมูลทั้งหมด

## โครงสร้างโปรเจกต์

```
core/            ตรรกะล้วน ไม่พึ่งเบราว์เซอร์ (มีเทส)
  src/date.rs      วันที่ เดือน
  src/model.rs     รายการ หมวด หมวดตั้งต้น
  src/format.rs    รูปแบบเงินกีบ ชื่อเดือนลาว
  src/summary.rs   ยอดรวม สัดส่วนหมวด กราฟ จัดกลุ่มตามวัน
  src/io.rs        ส่งออก/นำเข้า JSON และ CSV การรวมข้อมูล
src/             หน้าจอ Leptos
  state.rs         state ของแอป และการบันทึกลง localStorage
  platform.rs      ส่วนเชื่อมกับเบราว์เซอร์ (localStorage, ไฟล์, dialog)
  views/           home, list, report, settings, categories, editor
index.html       หน้าหลักของ Trunk และฟังก์ชัน JS สำหรับบันทึกไฟล์ (share sheet บน iPhone)
style.css        ธีมสว่าง/มืด ออกแบบสำหรับมือถือ
```

## เครื่องมือที่ต้องมี (Windows)

ติดตั้งไว้ในเครื่องนี้แล้ว หากย้ายไปเครื่องอื่นให้ติดตั้งตามนี้

1. Rust แบบ GNU: `rustup-init.exe --default-host x86_64-pc-windows-gnu --target wasm32-unknown-unknown`
2. MinGW-w64 สำหรับ `as.exe` และ `dlltool.exe`: `winget install BrechtSanders.WinLibs.POSIX.UCRT`
   และต้องให้โฟลเดอร์ `mingw64\bin` อยู่ใน PATH
3. Trunk: `cargo install trunk --locked --no-default-features --features native-tls`
4. wasm-bindgen ต้องเป็นเวอร์ชันเดียวกับใน `Cargo.lock`: `cargo install wasm-bindgen-cli --version =0.2.130 --locked`

> ถ้าอัปเดต dependency แล้ว `wasm-bindgen` ใน `Cargo.lock` เปลี่ยนเวอร์ชัน ให้ติดตั้ง `wasm-bindgen-cli` เวอร์ชันใหม่ให้ตรงกันด้วย

## คำสั่งที่ใช้บ่อย

```sh
trunk serve --offline              # รันตอนพัฒนา: http://127.0.0.1:8080
cargo test -p expenses-core        # รันเทสตรรกะหลัก
trunk build --release --offline    # build สำหรับใช้งานจริง ได้ไฟล์ในโฟลเดอร์ dist/
```

ลองบน iPhone ระหว่างพัฒนา (คอมกับมือถือต้องต่อ Wi-Fi วงเดียวกัน):
`trunk serve --offline --address 0.0.0.0` แล้วเปิด `http://<IP ของคอม>:8080` ใน Safari
(แบบนี้ยังใช้ออฟไลน์ไม่ได้ เพราะไม่ใช่ HTTPS)

## อัปขึ้น GitHub Pages

1. `trunk build --release --offline`
2. อัปไฟล์ทั้งหมดในโฟลเดอร์ `dist/` ขึ้น GitHub Pages (branch `gh-pages` หรือโฟลเดอร์ที่ตั้งไว้)

`Trunk.toml` ตั้ง `public_url = "./"` ไว้แล้ว ทุกไฟล์จึงอ้างอิงแบบ relative
และใช้ได้ทั้งที่ `https://<user>.github.io/` และ `https://<user>.github.io/<repo>/`

## ทำเป็น PWA

ใน `index.html` มีคอมเมนต์บอกตำแหน่งที่ต้องใส่ manifest, apple-touch-icon และโค้ดลงทะเบียน service worker

- ใช้ `<link data-trunk rel="copy-file" href="...">` เพื่อให้ Trunk คัดลอกไฟล์ เช่น manifest, ไอคอน และ `sw.js` ไปไว้ใน `dist/`
- ชื่อไฟล์ .js/.wasm/.css ที่ Trunk สร้างจะมี hash ต่อท้าย ถ้าอยากให้ service worker แคชได้ง่าย ให้ตั้ง `filehash = false` ใน `[build]` ของ `Trunk.toml`
- บน iPhone ให้เปิดเว็บด้วย **Safari** แล้วเลือก "เพิ่มไปยังหน้าจอโฮม"

## ข้อมูลและการสำรอง

- ข้อมูลเก็บใน localStorage key `lao-kip-expenses/data/v1` และการตั้งค่าเก็บใน `lao-kip-expenses/settings/v1`
- **ถ้าลบไอคอนแอปออกจากหน้าโฮม ล้างข้อมูล Safari หรือมือถือเสีย ข้อมูลจะหายทั้งหมด** ควรกด "ສົ່ງອອກໄຟລ໌ສຳຮອງ" เป็นประจำ แล้วบันทึกไฟล์ไว้ใน Files หรือ iCloud
- ถ้าอ่านข้อมูลเดิมไม่ได้ แอปจะเก็บสำเนาไว้ใน key `.../unreadable-<เวลา>` ก่อน แล้วจึงเริ่มข้อมูลใหม่ แอปจะไม่เขียนทับข้อมูลเดิม

### รูปแบบ CSV

```
ວັນທີ,ປະເພດ,ໝວດ,ຈຳນວນ (ກີບ),ໝາຍເຫດ
2026-11-11,ລາຍຈ່າຍ,ອາຫານ,45000,ເຝີ + ກາເຟ
```

- วันที่ใช้ได้ทั้ง `2026-11-11` และ `11/11/2026`
- ประเภทใช้ได้ทั้ง `ລາຍຈ່າຍ`/`ລາຍຮັບ` และ `expense`/`income`
- จำนวนเงินมีจุลภาคคั่นได้ เช่น `45,000`
- ถ้าชื่อหมวดยังไม่มีในแอป จะสร้างหมวดใหม่ให้ ถ้าเว้นว่าง จะลงหมวด "ອື່ນໆ"
- ตอนรวมกับข้อมูลเดิม รายการที่วันที่ ประเภท จำนวน หมวด และโน้ตเหมือนกันทุกอย่างจะถูกข้าม จึงนำเข้าไฟล์เดิมซ้ำได้โดยข้อมูลไม่ซ้ำ
